# s21_decimal

Реализация пользовательского типа данных `decimal` на языке C.

## Введение

Проект `s21_decimal` включает создание пользовательской версии библиотеки типа данных `decimal` на языке программирования C. Типы данных decimal важны для приложений, где критически важна точность вычислений с плавающей запятой, таких как финансовые и бухгалтерские программы. Цель проекта — обеспечить точные вычисления с использованием десятичных чисел, придерживаясь принципов структурного программирования.

### Обзор функций `decimal`

| №  | Функция | Описание |
| --- | -------- | ----------- |
| 1 | `int s21_add(decimal x, decimal y, decimal* result)` | Складывает два десятичных числа и сохраняет результат в `result` |
| 2 | `int s21_sub(decimal x, decimal y, decimal* result)` | Вычитает `y` из `x` и сохраняет результат в `result` |
| 3 | `int s21_mul(decimal x, decimal y, decimal* result)` | Умножает два десятичных числа и сохраняет результат в `result` |
| 4 | `int s21_div(decimal x, decimal y, decimal* result)` | Делит `x` на `y` и сохраняет результат в `result` |
| 5 | `int s21_mod(decimal x, decimal y, decimal* result)` | Вычисляет остаток от деления `x` на `y` и сохраняет результат |
| 6 | `int s21_floor(decimal x, decimal* result)` | Округляет `x` до ближайшего целого вниз и сохраняет результат |
| 7 | `int s21_round(decimal x, decimal* result)` | Округляет `x` до ближайшего целого и сохраняет результат |

| 9 | `int s21_negate(decimal x, decimal* result)` | Меняет знак числа `x` и сохраняет результат |
| 10 | `int s21_is_equal(decimal x, decimal y)` | Сравнивает два десятичных числа и возвращает 1, если они равны, иначе 0 |
| 11 | `int s21_is_not_equal(decimal x, decimal y)` | Возвращает 1, если числа не равны |
| 12 | `int s21_is_greater(decimal x, decimal y)` | Возвращает 1, если `x` больше, чем `y` |
| 13 | `int s21_is_less(decimal x, decimal y)` | Возвращает 1, если `x` меньше, чем `y` |
| 14 | `int s21_is_greater_or_equal(decimal x, decimal y)` | Возвращает 1, если `x` больше или равен `y` |
| 15 | `int s21_is_less_or_equal(decimal x, decimal y)` | Возвращает 1, если `x` меньше или равен `y` |

## Часть 1. Реализация функций библиотеки `s21_decimal`

Функции для пользовательской библиотеки `s21_decimal` были реализованы следующим образом:

- Библиотека была разработана на языке C, с использованием стандарта C11 и компилятора gcc;
- Исходный код библиотеки находится в директории `src`;
- В коде не использовались устаревшие и выведенные из употребления конструкции языка. Был принят во внимание стандарт POSIX.1-2017;
- При написании кода соблюдались правила оформления кода по Google Style;
- Решение оформлено в виде статической библиотеки под названием `s21_decimal.a` с заголовочным файлом `s21_decimal.h`;
- Все функции были протестированы с использованием unit-тестов на базе библиотеки Check;
- Unit-тесты сравнивают результаты пользовательской реализации с ожидаемыми результатами;
- Тесты покрывают как минимум 80% каждой функции;
- Подготовлен Makefile с целями для сборки библиотеки и запуска тестов (`all`, `clean`, `test`, `s21_decimal.a`, `gcov_report`);
- Формируется отчет о покрытии кода с использованием `gcov`, и результаты отображаются в формате HTML;
- Копирование реализации и использование стандартных библиотек decimal запрещено;
- Все функции написаны с соблюдением принципов структурного программирования, дублирование кода исключено.

## Сборка проекта

Для сборки проекта выполните следующие шаги:

1. Клонируйте репозиторий и перейдите в папку проекта:

    ```bash
    git clone <repository_url>
    cd <project_folder>
    ```

### Цели Makefile

- **make all**: Эта цель компилирует все исходные файлы и собирает статическую библиотеку `s21_decimal.a`.
- **make clean**: Эта цель удаляет все сгенерированные объектные файлы и исполняемые файлы, очищая проект.
- **make s21_decimal.a**: Эта цель собирает статическую библиотеку `s21_decimal.a` из исходных файлов проекта.
- **make test**: Эта цель компилирует и запускает все unit-тесты для проверки правильности работы функций библиотеки.
- **make gcov_report**: Эта цель запускает тесты с флагами покрытия кода и генерирует отчет о покрытии кода в HTML формате.

Данный проект реализует пользовательский тип данных `decimal` на языке C для работы с десятичными числами без ошибок округления. Проект выполнен с соблюдением принципов структурного программирования и включает всестороннее тестирование для обеспечения корректности и надежности реализации.
